# 验证记录

公开版本的验证针对软件行为，不是独立真实场景效果评估。

## 自动检查

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/frontend.test.mjs
python3 scripts/privacy_check.py --history
```

本地完成 27 项 Python 测试和 3 项前端逻辑测试，覆盖规则标签、复核优先级、自定义引用、归一化位置、导入限制、输出防覆盖、真实回环 HTTP、来源限制、请求内词库隔离、可选语义接口和隐私扫描器。没有 NumPy 的默认环境会跳过一项可选向量接口测试，CI 另有安装 NumPy 的独立语义接口任务。

另以 `python3 -S -m sensitive_detector scan --input examples/demo.txt` 确认默认命令不需要第三方 site-packages。安装后的独立环境从源码目录之外验证了 CLI，以及安装包中词库与 Web 资源的可用性和真实 HTTP 响应。

CI 在 Linux、Windows 的 Python 3.9 和 3.12 上运行默认测试、前端逻辑测试、历史隐私扫描和安装检查。各次运行结果以仓库 Actions 页面为准。

## 浏览器验收

实际浏览器完成：载入四条合成演示、执行检测、查看两条复核/一条引用/一条未命中、错误词库提示、旧结果导出失效、恢复词库、JSON 结果下载。导出文件的统计与网页显示一致。形如 HTML 图片标签的输入以原文显示，没有创建图片元素。

网页文件选择器导入和不同桌面尺寸未进行完整交互验收；TXT/CSV/JSONL 解析逻辑在 Python 测试中验证。

## 语义模式

本地曾使用已缓存的 `BAAI/bge-small-zh-v1.5` 模型，在阻断 socket 外连的条件下完成两条文本的真实推理；返回后端均为 `semantic`。这只验证本地加载和推理路径可运行，不构成准确率评估。

默认 CI 不下载模型，使用受控向量验证本地加载参数、模板处理和异常不会静默降级。模型本身不随仓库分发。其他模型、平台和组合未作全面验证。

## 发布隐私检查

公开树及全新历史扫描常见本地目录、私人邮箱、电话号码、身份号码、私钥和令牌格式，禁止报告、归档和模型文件入库。发布前另对已知私人身份字符串作本地检查，不把这些字符串写进公开扫描器。扫描与人工审阅均不能证明所有隐含身份信息都已消除；公开账号归属仍可见。
